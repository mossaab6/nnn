# محلل شام كاش (Sham Cash Analyzer)

تطبيق Android احترافي (Kotlin + Jetpack Compose، واجهة عربية من اليمين لليسار) يحلل معاملات محفظة **شام كاش**:
يقرأ إيصالات PDF الممسوحة ضوئياً، يقرأ إشعارات شام كاش تلقائياً، مربوط ببوت تيليجرام، ويعمل بالذكاء الاصطناعي **Grok (xAI)**.

> تطبيق شخصي مستقل، غير تابع لشركة شام كاش.

---

## المزايا

| الميزة | التفاصيل |
|---|---|
| الشاشة الرئيسية | مربع الرصيد الحالي + المستلم + المرسل، مع خيارات **اليوم / هذا الأسبوع / هذا الشهر / دائماً** (الافتراضي: دائماً)، رسم بياني لآخر 7 أيام، وقائمة المعاملات بسهم مائل ↗ أحمر للإرسال و ↙ أخضر للاستلام ومبلغ مثل `-193 $` أو `+100 $` |
| أول تشغيل | يطلب الرصيد الحالي (دولار، وليرة اختيارياً) واسمك في شام كاش، ثم إذن قراءة الإشعارات |
| تحليل PDF | تحويل النص الممسوح ضوئياً إلى نص (OCR عربي + إنجليزي **بدون إنترنت**) + قراءة Grok للصورة، ومقارنة القراءتين: إذا اختلف اسم أو مبلغ تُعلَّم المعاملة «تحتاج مراجعة» وتظهر القراءتان لتختار الصحيحة. الأسماء تُنسخ حرفياً (عربي/إنجليزي/نقاط/أرقام) |
| منع التكرار | كل معاملة تُفحص: نفس الملف، نفس رقم العملية، أو نفس المبلغ والنوع والشخص خلال 20 دقيقة. إذا قرأ التطبيق الإشعار ثم أضفت ملف PDF لنفس العملية **يدمجهما ولا يكررها** |
| قراءة الإشعارات | يقرأ إشعار شام كاش عند الاستلام/الإرسال ويضيف المعاملة تلقائياً (مع سجل للإشعارات) |
| الأشخاص | قائمة بكل شخص: كم أرسلت له وكم استلمت منه، بحث، ترتيب، تثبيت 📌، تعديل الاسم (ودمج)، حذف مع تأكيد، وزر **إضافة شخص** |
| إضافة يدوية | زر إضافة: نوع العملية، المبلغ، اسم المرسل، اسم المستلم، التاريخ والوقت، وحقول **اختيارية** (رقم العملية، الحسابات، العمولة، ملاحظة) + **تعبئة ذكية** من نص حر بالذكاء الاصطناعي |
| تفاصيل المعاملة | الضغط على أي معاملة يعرض كل التفاصيل: الوقت، المرسل، المستلم، الحسابات، رقم العملية، الملاحظة، المصدر، وفتح ملف الإيصال الأصلي |
| المساعد الذكي | محادثة مع Grok داخل التطبيق: «كم أرسلت هذا الأسبوع؟»، «من أكثر شخص استلمت منه؟». يستطيع حذف أو تثبيت أشخاص أو إضافة معاملات **لكن فقط بعد ضغطك زر التأكيد** |
| بوت تيليجرام | أرسل للبوت ملف PDF أو صورة إيصال فيحلله ويضيفه، أو اسأله أي سؤال. أوامر: `/balance` `/today` `/week` `/last` `/people` `/review`. أزرار تأكيد/إلغاء لكل حذف أو تعديل |
| المشاركة | من تطبيق شام كاش اضغط «مشاركة» على الإيصال واختر «محلل شام كاش» فيُحلَّل مباشرة |
| الإعدادات | الثيم (أخضر/أزرق/بنفسجي/ذهبي، داكن/فاتح، أسود كامل)، مفتاح Grok والنموذج، توكن تيليجرام ومعرف المحادثة (مع زر اكتشاف تلقائي)، الخدمة السحابية، الإشعارات، نسخ احتياطي |
| الأمان | التوكنات والمفاتيح مشفرة بـ Android Keystore، والبوت يتجاهل أي محادثة غير محادثتك |

## الخدمة السحابية لنقل ملفات PDF من تيليجرام (مجانية مدى الحياة)

بعد البحث، **أفضل خيار مجاني وغير محدود هو تيليجرام نفسه**: الملفات التي ترسلها للبوت تبقى على خوادم تيليجرام مجاناً وبدون حد لعددها، والتطبيق يحمّلها مباشرة (حتى 20 ميغابايت للملف، والإيصال حجمه ~80 كيلوبايت). لا تحتاج أي مفاتيح إضافية — هذا هو الوضع الافتراضي «مباشر».

**الحد الوحيد:** تيليجرام يحتفظ بالرسائل غير المستلمة 24 ساعة فقط. إذا كان هاتفك قد يبقى مطفأً أكثر من يوم، فعّل الخيار الاختياري **Cloudflare Worker** (مجاني: 100,000 طلب يومياً + قاعدة بيانات D1 مجانية) — يحفظ الرسائل حتى يتصل التطبيق، ويرد فوراً «تم استلام الملف». الكود جاهز في مجلد [`cloud-relay`](cloud-relay/README.md).

## كيف تحوّل المشروع إلى APK

### الطريقة 1 (الأسهل، بدون تحميل أي شيء على جهازك): GitHub Actions
1. افتح صفحة المستودع على GitHub ← تبويب **Actions** ← **Build APK**.
2. اضغط **Run workflow** (أو أي `push` يشغّله تلقائياً).
3. بعد انتهاء البناء (حوالي 5–10 دقائق) افتح التشغيل وحمّل **ShamCashAnalyzer-debug-apk** من قسم Artifacts، فك الضغط وثبّت `app-debug.apk` على هاتفك.

### الطريقة 2: Android Studio (موصى بها للتطوير)
1. حمّل وثبّت **Android Studio** من https://developer.android.com/studio (يحتوي JDK و Android SDK).
2. حمّل المشروع:
   ```cmd
   git clone https://github.com/mossaab6/nnn.git
   cd nnn
   git checkout claude/adoring-bohr-6a4gjh
   ```
3. في Android Studio: **File ← Open** واختر مجلد `nnn` نفسه (وليس مشروعاً آخر يحتويه) ← **New Window**. انتظر حتى ينتهي **Gradle Sync** (يحمّل الملفات تلقائياً في أول مرة — قد يستغرق وقتاً).
4. من القائمة: **Build ← Build App Bundle(s) / APK(s) ← Build APK(s)**.
5. الملف الناتج: `app\build\outputs\apk\debug\app-debug.apk`. أو صِل هاتفك بـ USB (مع تفعيل USB debugging) واضغط ▶️ Run.

### الطريقة 3: سطر الأوامر على Windows
تحتاج JDK 17 أو أحدث و Android SDK (أسهل طريقة للحصول عليهما: تثبيت Android Studio مرة واحدة).

في **PowerShell** (الطرفية الافتراضية في Android Studio) يجب كتابة `.\` قبل الأمر:
```powershell
cd nnn
Set-Content local.properties "sdk.dir=C:/Users/$env:USERNAME/AppData/Local/Android/Sdk"
.\gradlew.bat assembleDebug
```
وفي **cmd** العادي:
```cmd
cd nnn
echo sdk.dir=C:/Users/%USERNAME%/AppData/Local/Android/Sdk> local.properties
gradlew.bat assembleDebug
```
- أول تشغيل يحمّل Gradle (~150MB) والمكتبات (~500MB) — هذا طبيعي ومرة واحدة فقط.
- الناتج: `app\build\outputs\apk\debug\app-debug.apk`
- لتشغيل الاختبارات: `.\gradlew.bat testDebugUnitTest`

> ملاحظة: إذا ظهر خطأ اتصال عند تحميل الملفات من `dl.google.com` (بعض المناطق محجوبة)، استخدم VPN أثناء أول Sync فقط، أو استخدم الطريقة 1.

### للتحديث بدون فقدان البيانات (اختياري)
نسخة debug من أجهزة مختلفة تُوقَّع بمفاتيح مختلفة، فلن تُثبَّت فوق بعضها. لتوقيع ثابت أنشئ مفتاحاً مرة واحدة:
```cmd
keytool -genkeypair -v -keystore my-key.jks -alias shamcash -keyalg RSA -keysize 2048 -validity 10000
```
ثم أنشئ ملف `keystore.properties` بجانب `settings.gradle.kts` (لا ترفعه لـ GitHub):
```properties
storeFile=C:/path/to/my-key.jks
storePassword=...
keyAlias=shamcash
keyPassword=...
```
ولـ GitHub Actions أضف Secrets باسم `SIGNING_KEYSTORE_BASE64` و `SIGNING_STORE_PASSWORD` و `SIGNING_KEY_ALIAS` و `SIGNING_KEY_PASSWORD`.

## الإعداد بعد التثبيت

1. **أول فتح:** أدخل رصيدك الحالي واسمك في شام كاش (كما يظهر في الإيصالات) ثم فعّل «الوصول إلى الإشعارات».
2. **Grok:** أنشئ مفتاحاً من https://console.x.ai ← الإعدادات ← «الذكاء الاصطناعي Grok» ← الصق المفتاح ← «حفظ واختبار». النموذج الافتراضي `grok-4.7`، وإذا لم يكن متاحاً يختار التطبيق تلقائياً أحدث نموذج متاح (أو اضغط «جلب النماذج»).
3. **تيليجرام:**
   - افتح [@BotFather](https://t.me/BotFather) ← `/newbot` ← انسخ التوكن.
   - الإعدادات ← «بوت تيليجرام» ← الصق التوكن.
   - أرسل `/start` لبوتك من تيليجرام، ثم اضغط «اكتشاف» واختر محادثتك ← «حفظ واختبار» (ستصلك رسالة تأكيد).
   - فعّل «تشغيل البوت باستمرار» لرد فوري (وإلا يتحقق التطبيق كل 15 دقيقة).
4. **البطارية:** اضغط «استثناء» في قسم الإشعارات ليعمل التطبيق في الخلفية بدون انقطاع.
5. إذا لم يقرأ التطبيق إشعارات شام كاش: افتح «سجل الإشعارات» أو أضف اسم حزمة شام كاش يدوياً (التطبيق يقترح التطبيقات التي ترسل إشعارات مالية).

## هيكل المشروع

```
app/src/main/java/com/smartcash/analyzer/
├── domain/        منطق نقي ومختبَر: تحليل نص الإيصال، المبالغ، التواريخ، الإشعارات، منع التكرار، الأرصدة
├── data/          Room (المعاملات، الأشخاص، المحادثة، الإجراءات، سجل الإشعارات) + الإعدادات المشفرة + النسخ الاحتياطي
├── ocr/           عرض صفحات PDF + Tesseract (عربي/إنجليزي) بقراءة عمود القيم وعمود العناوين بشكل منفصل
├── ai/            عميل Grok، استخراج الإيصالات، المساعد مع الأدوات (Tools) والإجراءات التي تحتاج تأكيد
├── analyze/       خط التحليل الكامل: OCR + Grok + مقارنة + تحديد الإرسال/الاستلام + الحفظ
├── telegram/      Bot API، معالجة الرسائل والأزرار، المزامنة الدورية، خدمة البوت، Relay
├── notifications/ قارئ إشعارات شام كاش
└── ui/            كل الشاشات (Compose)
cloud-relay/       Cloudflare Worker الاختياري
```

اختبارات الوحدة في `app/src/test` (مبنية على نص OCR حقيقي لإيصال شام كاش مع أسماء مستعارة).
